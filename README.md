# Technocore Verificador - Aledepa

Herramienta simple en Python para verificar el estado de un agente en Technocore.

## ¿Qué hace?
- Muestra tu DID y fingerprint
- Verifica si el perfil DID está publicado
- Genera un proof listo para usar

## Cómo usar
1. Coloca tu archivo `.technocore-key.json` en la misma carpeta o modifica la ruta en el código
2. Ejecuta:
```bash
python verificador_aledepe.py
